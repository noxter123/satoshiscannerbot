# SatoshiScannerBot

**Telegram-бот для мониторинга новых криптовалют.**  
Отслеживает самые свежие монеты с CoinMarketCap и отправляет их в Telegram.

---

## Возможности

- Команда `/start` — приветственное сообщение
- Команда `/newcoins` — выводит список новых монет с CoinMarketCap
